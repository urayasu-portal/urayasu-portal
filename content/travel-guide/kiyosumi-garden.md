休息日のすべてにアトラクションが要るわけではありません。家族に必要なのが**2時間の静けさ**──鯉の池、飛び石、きちんと淹れたコーヒー、小さな博物館──なら、行き先は江東区の運河沿いの古い街**清澄白河**です。東京にしては幸運なことに、**浦安駅から乗換1回・20分**。中心は150円で入れて子どもは無料の明治の回遊式庭園**清澄庭園**。その周りに、この街を東京のコーヒーの街にしたロースターたち（ブルーボトルの日本1号店はここ）、東京都現代美術館、そして子どもが1840年代の町並みに入れる深川江戸資料館があります。

## こんな人におすすめ

- パーク2日を終えて、**行列なしで美しい場所に座りたい**大人。
- カモ、飛び石、ケーキで満足する幼児がいて、昼寝の時間を確保したい家族。
- コーヒー好き。
- 都心の有名庭園のような団体客の混雑なしに、穏やかな「日本庭園」を体験したい人。

{{< note >}}
**どんな「日本庭園」？** 回遊式庭園──大きな池の周りの園路、全国から集めた名石、水の上に張り出した茶室風の建物、季節の花。枯山水でも花の公園でもなく、楽しみはゆっくり歩くことにあります。所要45〜60分。
{{< /note >}}

## 見どころと体験

### 清澄庭園（150円・子ども無料）

| | |
|---|---|
| **開園時間** | 9:00〜17:00（入園16:30まで） |
| **休園日** | 12月29日〜1月1日 |
| **入園料** | 一般150円／65歳以上70円／小学生以下無料（都内在住・在学の中学生無料） |
| **無料公開日** | 5月4日、10月1日 |
| **アクセス** | 清澄白河駅（都営大江戸線E14／東京メトロ半蔵門線Z11）徒歩3分 |
| **備考** | ペット不可、駐車場なし、車椅子ルート図あり |

池を巡る園路は、鯉や亀の上を数メートル歩ける**磯渡り（飛び石）**──子どもが覚えて帰る部分──と、池に張り出す**涼亭**を通ります。木陰のベンチと芝生の広場も。紅葉は11月下旬、夏は本当の木陰がある数少ない都心の庭園です。

### コーヒー：ロースターの街

庭園と現代美術館の間の通りが、東京のサードウェーブコーヒー発祥の地。中心は**ブルーボトルコーヒー 清澄白河フラッグシップカフェ**（平野1-4-8、**毎日8:00〜19:00**、47席、Wi-Fi）。倉庫を改装し、2015年にブルーボトル初の米国外店舗として開業しました。数ブロック内に小さな自家焙煎店がいくつもあり、多くは午前の半ばに開いて18:00までに閉まり、月曜や不定休の店も──ブルーボトル以外の営業時間は「当日要確認」として扱ってください。子連れのコツはテイクアウトして庭園のベンチ、または清澄通り沿いの広めのカフェ。

### 深川江戸資料館（子ども向き）

駅（A3出口）から5分：1840年代の江戸の運河沿いの町を実物大で再現した屋内展示──入れる長屋、八百屋、船、火の見櫓、夜明けから夜までを繰り返す照明。**9:30〜17:00（入館16:30まで）、第2・第4月曜休館、大人400円、小・中・高校生50円。** ボランティアガイドが英語で説明してくれることも。所要約45分、ほとんどのものに触れます。

### 東京都現代美術館（MOT）

駅B2出口から徒歩9分、木場公園の中。充実した図書室、カフェ、芝生のある大型の現代美術館。**10:00〜18:00（入場17:30まで）、月曜休館（祝日の月曜は翌日）と年末年始、コレクション展は一般500円、大学生400円、高校生・65歳以上250円、中学生以下無料。** 企画展は別料金。展示替えの休館（2027年1〜2月に数週間）があるのでカレンダー確認を。

## 東京ディズニーリゾート周辺からの行き方

**浦安駅（東西線）から──楽なルート：**

1. **東西線**で**門前仲町**へ（快速2駅・各駅停車6駅、約11〜14分・209円）。
2. **都営大江戸線**で1駅、**清澄白河**（約2分）。

**約20分・IC317円**（メトロ⇔都営の70円乗継割引はICカードで自動適用）、乗換1回。庭園はA3出口から3分。

**舞浜（京葉線）から：**

1. **JR京葉線**で**新木場**（約6分・199円）。
2. **有楽町線**で**月島**（約7分）。
3. **大江戸線**で2駅、**清澄白河**。

**約35分・485円**、乗換2回。メトロだけの別案（八丁堀→日比谷線で人形町→徒歩で水天宮前→半蔵門線1駅）は431円でほぼ同じ時間ですが、駅間の地上歩きがあります。

**新浦安から：** バスで浦安駅へ出て東西線ルートのほうが京葉線ルートより楽なことが多いです──[駅別バス乗り場](/life-guide/bus-noriba/)参照。

上記すべてSuica/PASMO可。クレジットカードのタッチ乗車は東京メトロ・都営で使えますがJR京葉線では不可。

## 子連れ・雨の日の注意

- **ベビーカー：** 庭園の主園路（砂利）は可、飛び石は不可。2つの博物館はエレベーターあり、深川の館内は単層。
- **トイレ：** 庭園入口付近と両博物館。
- **雨：** 小雨の庭園は静かで風情があり、2つの博物館が雨の午後をカバー。本降りだと砂利道に水たまりができるので、ベビーカーのレインカバーを。
- **食事：** カフェはどこも小さく、週末の午後は満席。昼食は早めに。
