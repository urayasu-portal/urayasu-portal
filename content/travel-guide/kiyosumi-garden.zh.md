不是每个休息日都需要一个景点。如果你家需要的是**两小时的安静**——一池锦鲤、踏石、一杯好好冲的咖啡和一座小博物馆——那地方就是**清澄白河**，江东区一处运河边的老街区，而且托东京的福，**从浦安站只要20分钟、换乘1次**。它的中心是**清澄庭园**，一座明治时代的回游式庭园，门票150日元，儿童免费；周围是让这一带成为东京咖啡之城的烘焙坊（Blue Bottle在日本的第一家店就在这里）、东京都现代美术馆，以及孩子可以走进1840年代复原街道的深川江户资料馆。

## 适合这样的你

- 玩了两天乐园、想**在一个美丽的地方坐下来**、不用排队的大人。
- 有看到鸭子、踏石和一块蛋糕就满足的幼儿，而且需要留出午睡时间的家庭。
- 咖啡爱好者。
- 想要一次温和的「日本庭园」体验，又不想碰上著名市中心庭园那种旅游大巴人潮。

{{< note >}}
**这是哪一种「日本庭园」？** 回游式庭园——围绕一个带小岛的大池塘的步道、从日本各地运来的名石、一座伸向水面的茶室式建筑，以及四季花卉。它既不是枯山水，也不是花园公园；乐趣在于慢慢走。安排45〜60分钟。
{{< /note >}}

## 看什么、做什么

### 清澄庭园（150日元，儿童免费）

| | |
|---|---|
| **开放时间** | 9:00〜17:00（截止入园16:30） |
| **休园日** | 12月29日〜1月1日 |
| **门票** | 大人150日元／65岁以上70日元／小学生及以下免费（在东京居住或就学的初中生免费） |
| **免费开放日** | 5月4日、10月1日 |
| **交通** | 清澄白河站（都营大江户线E14／东京地铁半藏门线Z11）步行3分钟 |
| **备注** | 禁止宠物；无停车场；有轮椅路线图 |

绕池的路线会经过**踏石（矶渡）**——让你在水面上走出几米，脚下是锦鲤和乌龟，这是孩子会记住的部分——以及伸向池面的**凉亭**。树荫下有长椅，还有一片草坪。红叶在11月下旬到来；夏天，它是少数真正有树荫的市中心庭园之一。

### 咖啡：烘焙坊街区

庭园和现代美术馆之间的街道，是东京第三波咖啡浪潮的起点。核心是**Blue Bottle Coffee 清澄白河旗舰店**（平野1-4-8，**每天8:00〜19:00**，47个座位，有Wi-Fi），由仓库改造，2015年作为Blue Bottle美国之外的第一家店开业。几个街区内还有多家小型独立烘焙坊；多数上午过半开门、18:00前打烊，有的周一休或不定休——除了Blue Bottle的时间，其他都当作「当天再确认」。带孩子的诀窍是外带咖啡去庭园的长椅，或者去清澄通沿线更宽敞的咖啡馆。

### 深川江户资料馆（适合孩子的那一座）

离车站（A3出口）5分钟：一处1840年代江户运河边街区的实物大、可走进去的复原——可以踏入的长屋、蔬菜店、一艘船、一座火望楼，灯光从黎明循环到夜晚。**9:30〜17:00（截止入馆16:30），第2、第4个周一休馆；大人400日元，小学生至高中生50日元。** 志愿导览员常会用英语讲解。约45分钟；多数东西孩子都可以触摸。

### 东京都现代美术馆（MOT）

从车站B2出口步行9分钟，位于木场公园内：一座大型当代艺术馆，有不错的图书室、咖啡馆和户外草坪。**10:00〜18:00（截止入场17:30），周一休馆（周一逢节假日则顺延至次日）及年末年始；馆藏展大人500日元、大学生400日元、高中生及65岁以上250日元、初中生及以下免费。** 特展另行定价。请查看休馆日历——换展期间会闭馆（2027年1〜2月有数周）。

## 从东京迪士尼度假区周边怎么去

**从浦安站（东西线）出发——轻松的路线：**

1. 搭**东西线**到**门前仲町**（快速2站·各站停车6站，约11〜14分钟·209日元）。
2. 换**都营大江户线**1站到**清澄白河**（约2分钟）。

**约20分钟·IC卡317日元**（地铁⇔都营的70日元换乘折扣用IC卡会自动适用），换乘1次。庭园离A3出口3分钟。

**从舞滨（京叶线）出发：**

1. 搭**JR京叶线**到**新木场**（约6分钟·199日元）。
2. 换**有乐町线**到**月岛**（约7分钟）。
3. 换**大江户线**2站到**清澄白河**。

**约35分钟·485日元**，换乘2次。只走东京地铁的替代方案（经八丁堀：日比谷线到人形町，步行到水天宫前，半藏门线1站）431日元，时间差不多，但要在两站之间走一段地面路。

**从新浦安出发：** 搭巴士到浦安站再走东西线路线，往往比京叶线路线更简单——见[各站公交乘车处](/zh/travel-guide/station-bus-stops/)。

以上都能用Suica/PASMO；信用卡闪付乘车在东京地铁和都营地铁可用，但JR京叶线不行（支付宝／微信扫码不能过闸）。

## 慢节奏的半日计划

| 时间 | 内容 |
|---|---|
| 9:30 | 离开浦安站；10:00前在一家烘焙坊喝咖啡、吃点面包 |
| 10:30 | 清澄庭园——慢慢绕一圈、踏石、长椅（45〜60分钟） |
| 11:45 | 深川江户资料馆（带孩子）或MOT（青少年和大人） |
| 13:00 | 在清澄通吃午餐——荞麦面、咖喱和面包店是本地的选择 |
| 14:30 | 回酒店午睡；或搭大江户线2站去[两国](/zh/travel-guide/ryogoku-sumo/)，4站去[筑地](/zh/travel-guide/tsukiji-outer-market/) |

## 带孩子，以及下雨时

- **婴儿车：** 庭园的主园路（碎石）没问题，踏石不行；两座博物馆都有电梯，深川资料馆内部是单层。
- **洗手间：** 庭园入口附近和两座博物馆都有。
- **下雨：** 小雨中的庭园安静而有情调，两座博物馆能撑起一个下雨的下午；大雨会让碎石路积水——带上婴儿车的雨罩。
- **吃饭：** 多数咖啡馆都很小；周末下午会坐满。午餐早点吃。
