不是每個休息日都需要一個景點。如果你們一家需要的是**兩小時的安靜**——有錦鯉的池塘、飛石、一杯好好沖的咖啡、一座小博物館——那地方就是**清澄白河**，江東區一個運河旁的老街區，而且幸運得很東京：**從浦安站轉乘1次、20分鐘**。它的核心是**清澄庭園**，一座明治時代的回遊式庭園，入園150日圓、兒童免費；周圍是讓這一帶成為東京咖啡之町的烘焙所（藍瓶咖啡的日本第一家店就在這裡）、東京都現代美術館，以及孩子可以走進1840年代復原街道的深川江戶資料館。

## 適合這樣的你

- 玩完兩天樂園、想**不排隊坐在一個美麗的地方**的大人。
- 帶著幼兒、只要有鴨子、飛石和一塊蛋糕就滿足，而且需要保留午睡時間的家庭。
- 咖啡人。
- 想要一個溫和的「日本庭園」體驗，不想碰上市中心名園那些旅行團人潮。

{{< note >}}
**這是哪一種「日本庭園」？** 回遊式庭園——繞著一座有小島的大池的園路、從日本各地運來的名石、一座伸向水面的茶室式涼亭，以及四季的花。它不是枯山水，也不是花卉公園；樂趣在於慢慢走。預留45〜60分鐘。
{{< /note >}}

## 看什麼、玩什麼

### 清澄庭園（150日圓，兒童免費）

| | |
|---|---|
| **開放時間** | 9:00〜17:00（最後入園16:30） |
| **休園日** | 12月29日〜1月1日 |
| **入園費** | 大人150日圓／65歲以上70日圓／國小生以下免費（居住或就學於東京都內的國中生免費） |
| **免費開放日** | 5月4日、10月1日 |
| **交通** | 清澄白河站（都營大江戶線E14／東京Metro半藏門線Z11）步行3分鐘 |
| **備註** | 禁止寵物；無停車場；有無障礙路線圖 |

繞池的園路會經過**飛石步道（磯渡）**——讓你走到水面上幾公尺、腳下是錦鯉與烏龜——那是孩子會記住的部分——以及伸向池中的**涼亭**。有樹蔭下的長椅和草坪區。紅葉在11月下旬；夏天它是少數真正有樹蔭的市中心庭園之一。

### 咖啡：烘焙所的街區

庭園與現代美術館之間的街道，是東京第三波咖啡的起點。核心是**藍瓶咖啡 清澄白河旗艦咖啡廳**（平野1-4-8，**每天8:00〜19:00**，47席，有Wi-Fi），由倉庫改建，2015年以藍瓶咖啡美國以外第一家店開幕。幾個街區內有好幾家小型獨立烘焙所；多數上午中段開門、18:00前打烊，有些週一休或不定休——除了藍瓶的營業時間之外，其他都請當作「當天再確認」。帶孩子的訣竅是外帶咖啡到庭園的長椅上喝，或選清澄通沿線空間較大的咖啡廳。

### 深川江戶資料館（給孩子的那一座）

離車站（A3出口）5分鐘：1840年代江戶運河街區的實物大、可走入的復原——可以走進去的長屋、蔬果店、一艘船、一座火警瞭望台，燈光從黎明循環到夜晚。**9:30〜17:00（入館至16:30），第2、第4個週一休館；大人400日圓、國小至高中生50日圓。** 志工導覽常以英語解說。約45分鐘；孩子可以碰大多數的東西。

### 東京都現代美術館（MOT）

從車站B2出口步行9分鐘，在木場公園內：一座大型當代美術館，有不錯的圖書室、咖啡廳與戶外草坪。**10:00〜18:00（入館至17:30），週一休館（週一逢國定假日則隔天休館）及年末年初休館；典藏展大人500日圓、大學生400日圓、高中生與65歲以上250日圓、國中生以下免費。** 特展另計。請查休館日曆——換展期間會休館（2027年1〜2月有數週）。

## 從東京迪士尼度假區周邊怎麼去

**從浦安站（東西線）——輕鬆的那條：**

1. 搭**東西線**到**門前仲町**（快速2站·各站停車6站，約11〜14分鐘·209日圓）。
2. 搭**都營大江戶線**1站到**清澄白河**（約2分鐘）。

**約20分鐘·IC卡317日圓**（用IC卡會自動套用70日圓的Metro–都營轉乘優惠），轉乘1次。庭園離A3出口3分鐘。

**從舞濱（京葉線）：**

1. 搭**JR京葉線**到**新木場**（約6分鐘·199日圓）。
2. 搭**有樂町線**到**月島**（約7分鐘）。
3. 搭**大江戶線**2站到**清澄白河**。

**約35分鐘·485日圓**，轉乘2次。只用Metro的替代路線（經八丁堀：日比谷線到人形町、步行到水天宮前、半藏門線1站）為431日圓、時間差不多，但車站之間要走一段地面路。

**從新浦安：** 搭巴士到浦安站再走東西線路線，往往比京葉線路線簡單——見[各車站巴士站牌](/zh-tw/travel-guide/station-bus-stops/)。

以上都能用Suica／PASMO；感應式信用卡可用於東京Metro與都營地鐵，但JR京葉線不行。

## 慢步調的半日行程

| 時間 | 內容 |
|---|---|
| 9:30 | 離開浦安站；10:00前在烘焙所喝咖啡配麵包 |
| 10:30 | 清澄庭園——慢慢繞一圈、飛石、長椅（45〜60分鐘） |
| 11:45 | 深川江戶資料館（孩子）或MOT（青少年與大人） |
| 13:00 | 在清澄通吃午餐——蕎麥麵、咖哩與麵包店是在地選項 |
| 14:30 | 回飯店午睡，或搭大江戶線2站到[兩國](/zh-tw/travel-guide/ryogoku-sumo/)、4站到[築地](/zh-tw/travel-guide/tsukiji-outer-market/) |

## 親子·雨天注意事項

- **嬰兒車：** 庭園的主碎石園路沒問題，飛石不行；兩座博物館都有電梯，深川的館內是單一樓層。
- **廁所：** 庭園入口附近與兩座博物館。
- **下雨：** 小雨中的庭園安靜又有情調，兩座博物館可以撐過一個下雨的下午；大雨會讓碎石路積水——帶嬰兒車雨罩。
- **食物：** 多數咖啡廳很小，週末下午會客滿。午餐早點吃。
