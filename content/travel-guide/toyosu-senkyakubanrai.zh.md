走出百合海鸥号的市场前站，连廊直接通向一条挂着灯笼的木造街道——**丰洲 千客万来**，坐落在东京最大鱼市场旁、以江户为主题的美食与温浴综合设施。对住在东京迪士尼度假区周边的人来说，它有两个大多数东京「美食景点」没有的优点：**从舞滨经新木场约30分钟**就到；吃了太多金枪鱼之后，还有**免费的屋顶足汤**和**24小时营业的温泉**，让走累了的双腿泡一泡。它离teamLab Planets也只有步行10分钟，所以本地人习惯把两者当作同一次出行。

## 适合这样的你

- 旅途中想认认真真吃一次日本海鲜——寿司、海鲜盖饭、烤扇贝、串在竹签上的玉子烧——又不想凌晨5点起床。
- 要和[teamLab Planets](/zh/travel-guide/teamlab-planets/)搭配，需要一个步行可达的午餐＋恢复体力的地方。
- 想泡一个比酒店浴室更大、随时都开、坐电车就能到的温泉。
- 家里有孩子，排寿司队的时候给他一根串就能安静。

{{< note >}}
**关于名称。** 美食设施部分在2025年9月1日之前叫「丰洲场外 江户前市场」，之后整个园区统一改名为**丰洲 千客万来**。指示牌、地图和旧文章两个名字都会出现，其实是同一个地方。隔壁的批发市场**丰洲市场**是另一处设施，参观区域有限。
{{< /note >}}

## 能玩什么？

### 江户风海鲜街（2〜3楼）

主楼以木材和白灰墙重现江户时代商家街道，两三层楼高，沿街是寿司柜台、海鲜盖饭店、烤海鲜摊、玉子烧、高汤、和果子和伴手礼店。吃法是站在柜台、坐小桌子，或到3楼露台。价格从一串、一份甜点几百日元，到东京寿司柜台的常规水平；海鲜盖饭2,000〜4,000日元是市场一带的典型价位。

**营业时间：** 商店**10:00〜18:00**；餐饮店**10:00〜22:00**（部分20:00打烊，少数9:00开门）。**全年无休**，市场休市日也营业。有免费Wi-Fi（SSID「SENKYAKU_BANRAI」）。信用卡、手机支付、交通IC卡「视店铺而定」——给摊位备一些现金。

### 免费足汤庭园（8楼）

从2楼后方上去就是**足汤庭园**：长长的足汤池、越过市场吊车眺望东京湾的屋顶庭园，还有给负责拿冰淇淋的人坐的长椅。**免费、无需温泉门票、9:00〜22:00。** 对于昨天走了2万步的双脚，这是最值得的20分钟。请自带小毛巾（或现场购买）；活动日会缩短开放时间，花火大会当天（2026年10月24日）全天关闭。

### 东京丰洲 万叶俱乐部——24小时温泉（高楼）

温浴楼**全年无休、24小时营业**，浴场3:00〜5:00清扫。标准的当日套餐——**大人（初中生以上）3,850日元＋入汤税150日元**——含浴衣、浴巾和小毛巾，空手去就行。儿童更便宜（小学生2,000日元；3〜5岁1,400日元；3岁以下免费，以2026年价目表为准——出发前请查官方页面）。馆内有从箱根、汤河原运来温泉水的室内浴池和露天浴池、展望足汤（10楼，仅限温泉客人）、躺椅休息层、餐厅，以及**包场家庭浴室（每小时4,500日元）**——有纹身或孩子害羞、不方便进大浴场时的选项。3:00以后加收深夜费；真要在丰洲过夜，也有住宿房间。

纹身规定和毛巾细则见官方网站；和日本多数温浴设施一样，可见的纹身可能被拒，家庭浴室是变通办法。另外提醒：日本的温泉是**不穿泳衣的裸汤**，男女分开入浴，6岁以下的孩子可以跟随异性家长。

{{< warn >}}
**丰洲市场的金枪鱼拍卖不属于这座设施。** 从参观台看拍卖是免费的，但**需要提前抽签**（每月在线申请，5:30集合）；一般的2楼参观通道（5:00〜17:00）在市场休市日——周日、节假日和多数周三——关闭。如果拍卖对你很重要，请另行安排，并做好早起的准备。
{{< /warn >}}

## 从东京迪士尼度假区周边怎么去

**从舞滨出发：**

1. 搭**JR京叶线**到**新木场**——2站·约6分钟·IC卡199日元。
2. 换**东京地铁有乐町线**到**丰洲**——2站·约5分钟·178日元。
3. 换**百合海鸥号（Yurikamome）**1站到**市场前**——3分钟·189日元。车站2楼的连廊直通设施（步行约4分钟）。

**单程约30分钟·566日元**，两次换乘都很短，全程在地下或有顶棚。从新浦安出发，京叶线再加1站（3分钟）。

**不坐百合海鸥号：** 从丰洲站步行约20分钟——天气好的话很舒服，但在市场吃完午饭推着婴儿车就嫌长了。

**从浦安站（东西线）出发：** 门前仲町离丰洲不远，但没有直达的铁路；可从门前仲町打车（约10分钟），或走东西线→有乐町线（经饭田桥，绕远）。如果酒店在浦安站附近，这一天值得坐巴士到新浦安再搭京叶线。

三条线路都能用Suica/PASMO。百合海鸥号支持信用卡闪付乘车，但JR京叶线不支持（支付宝／微信扫码不能过闸）——见[IC卡·支付攻略](/zh/travel-guide/ic-card-payment/)。

## 半日计划（搭配teamLab）

| 时间 | 内容 |
|---|---|
| 10:00 | 用上午的指定时段票进teamLab Planets（2〜3小时，赤脚——见[teamLab攻略](/zh/travel-guide/teamlab-planets/)） |
| 13:00 | 步行约10分钟（或百合海鸥号1站）到千客万来；等12点的高峰缓和后吃晚午餐 |
| 14:30 | 在2楼买小吃和伴手礼——玉子烧、高汤、海产干货 |
| 15:00 | 8楼免费足汤，20〜30分钟 |
| 15:45 | 可选：万叶俱乐部泡汤（2小时）——或者回去在[舞滨欧亚温泉](/zh/travel-guide/maihama-eurasia-spa/)泡 |
| 18:00 | 回到舞滨 |

不去teamLab的话，开门（10:00）就到，寿司队最短，下午回乐园也绰绰有余。

## 带孩子，以及下雨时

- **婴儿车**可以带入（没有停放处，所以得推着穿过街道）。各楼层有电梯连接；多功能洗手间在1〜3楼，**哺乳室在温浴楼2楼和市场楼3楼**。
- **挑食的孩子：** 玉子烧、烤饭团、菠萝包、霜淇淋和串烧到处都有；3楼还有一家海鲜自助餐厅，可以坐下来慢慢选。
- **下雨：** 街道有顶棚，温泉在室内；只有足汤和露台是露天的（小雨时足汤仍可使用）。和teamLab组合，是不错的雨天搭配。
- **人潮：** 周末中午前后非常拥挤；工作日开门时段很清静。

## 顺道一起玩

- [teamLab Planets（丰洲）](/zh/travel-guide/teamlab-planets/)——步行10分钟；先订好指定时段票，再把这里的午餐安排在前后。
- [台场与免费喷泉秀](/zh/travel-guide/odaiba/)——百合海鸥号从市场前继续开往对岸的台场（约15分钟·IC卡325日元）：市场午餐，然后看15:00或傍晚的喷泉。
- [筑地场外市场](/zh/travel-guide/tsukiji-outer-market/)——更老、更密集、只在上午的「老大哥」。二选一：要气氛和9点开始的，去筑地；要舒适、带孩子、泡温泉的，去丰洲。
- [舞滨欧亚天然温泉](/zh/travel-guide/maihama-eurasia-spa/)——想回酒店附近再泡的话。
