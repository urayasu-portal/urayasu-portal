東京的地標裡，只有**東京晴空塔**是它來找迪士尼度假區，而不是反過來：**從東京迪士尼海洋與東京迪士尼樂園的巴士站有直達巴士**開往東京晴空塔城，1,000日圓、免預約、約45〜55分鐘——沒有東京車站、沒有轉乘、沒有樓梯。到了那一頭，有634公尺的高塔與兩座展望台、小小孩常常比景色更愛的**墨田水族館**，以及有300家店、美食樓層和一家人需要的育嬰室的**東京晴空街道（Solamachi）**。它也是最能自然搭配[淺草](/zh-tw/travel-guide/asakusa/)的東京景點——過河步行20分鐘。

## 適合這樣的你

- 想要**一次東京高處景觀**，而且寧願搭巴士也不想推著嬰兒車轉地鐵的家庭。
- **下雨或寒冷的日子**：展望台、水族館與商場全在室內（天氣只能毀掉景色）。
- 淺草的一天，需要一個室內的下半場。
- 正在拿晴空塔和[SHIBUYA SKY](/zh-tw/travel-guide/shibuya-sky/)比較的人：晴空塔更高、室內、兒童更便宜、有巴士直達；SHIBUYA SKY是露天的、更上相。

{{< note >}}
**票價在2026年4月改制了。** 晴空塔改為**依日期浮動的票價制**：以前的平日／假日、預售／當日、大人／中人／小人固定價目表都沒有了。官方網站依日期顯示票價；年齡區分改為**大人15歲以上、兒童6〜14歲、未滿6歲免費**。引用「2,100日圓／3,100日圓」固定票價的舊攻略已經過時。
{{< /note >}}

## 能玩什麼？

### 展望台

- **天望甲板（350m）：** 三層樓的360度景觀、一段玻璃地板、咖啡廳與商店。冬天晴朗的日子看得到富士山；一般的日子，一路延伸到地平線的城市就是重點。
- **天望迴廊（450m）：** 再往上爬100公尺的螺旋玻璃走廊——「空中漫步」的部分。可買套票，或當天在甲板的售票機加購（**大人1,400日圓／兒童700日圓**）。

**營業時間（2026年10月）：平日10:00〜22:00、週六日9:00〜22:00，最後入場為關閉前1小時。** 最佳時段是一開門（隊伍短、能見度最好）和日落前一小時（一張票收齊白天、夕陽與夜景，但也最擠——請事先預約那個時段）。

### 2026年的門票

| | |
|---|---|
| **天望甲板** | 大人（15歲以上）**1,800日圓起**、兒童（6〜14歲）**900日圓起**；未滿6歲免費 |
| **甲板＋迴廊套票** | 大人**3,000日圓起**、兒童**1,500日圓起** |

### 墨田水族館（東京晴空街道5〜6樓）

一座燈光打得很美的中型水族館：可以從上方俯瞰的開放式麥哲倫企鵝池、水母區、巨大的「江戶金魚」展區，還有海狗。**每天營業——平日10:00〜20:00、週六日國定假日9:00〜21:00，入場至閉館前1小時。大人2,700日圓、高中生2,000日圓、國小·國中生1,400日圓、3歲以上900日圓。** 昏暗、安靜、適合嬰兒車，約90分鐘——帶幼兒的雨天，它可以是主角，展望台整個跳過也行。

### 東京晴空街道——塔底下的商場

**全館10:00〜21:00；餐廳樓層（6〜7樓與30〜31樓）11:00〜23:00。** 大型美食街與地下食品街解決午餐；30〜31樓的餐廳附帶近乎免費的景觀（你付的是餐費）。親子設施：**1樓、3樓、4樓有附尿布台、哺乳室、熱水與微波爐的育嬰室**；塔本身在4樓有嬰兒車停放區、數量有限的嬰兒車租借、4樓置物櫃，展望台內有哺乳室。這裡也有角色商店（包括大型的寶可夢中心、吉卜力，以及需預約的卡比咖啡廳）——是[東京角色街](/zh-tw/travel-guide/tokyo-character-street/)的縮小版。

## 從東京迪士尼度假區周邊怎麼去

**直達巴士（從樂園與舞濱飯店出發最簡單）：** **晴空塔接駁巴士**（東武巴士／京成巴士）往返**東京晴空塔城（2號站牌）－錦糸町站－（部分班次停葛西站）－東京迪士尼海洋－東京迪士尼樂園**。**大人1,000日圓、兒童500日圓**；從樂園出發16班（迪士尼海洋9:40〜21:25；迪士尼樂園9:50〜21:35），往樂園17班（晴空塔城發車6:50〜19:50）。**到迪士尼海洋約45分鐘、到迪士尼樂園55分鐘**。不接受預約——先到先上，且不設站位，想看完夕陽再回去的話請提早15分鐘排隊。車上可用現金、Suica／PASMO與感應式信用卡。

**從浦安站（東西線）搭電車：** 東西線到**九段下**，半藏門線到**押上**（塔正下方的車站）——**約45〜50分鐘·IC卡252日圓**，轉乘1次。較快但較貴：東西線到日本橋，都營淺草線到押上——約36分鐘·359日圓。

**從舞濱搭電車：** 京葉線到八丁堀、日比谷線到人形町、都營淺草線到押上——約45分鐘，大約540日圓（估算）。老實說，搭巴士吧。

在**押上站**跟著東京晴空塔城的指標走；塔的入口在4樓，從閘門搭手扶梯與電梯約7分鐘。

以上都能用Suica／PASMO；感應式信用卡可用於東京Metro、都營地鐵與巴士，但JR京葉線不行。

## 巴士來回的行程

| 時間 | 內容 |
|---|---|
| 9:50 | 從東京迪士尼樂園巴士站搭晴空塔接駁巴士（迪士尼海洋為9:40） |
| 10:45 | 抵達晴空塔城；先去墨田水族館（上午很安靜） |
| 12:30 | 在東京晴空街道的美食樓層吃午餐 |
| 14:00 | 用預約的時段上天望甲板（或步行20分鐘去淺草，再回來看夕陽） |
| 16:30 | 逛東京晴空街道的商店；吃點心 |
| 17:30 | 搭巴士回樂園或飯店，約18:30抵達 |

想在展望台看夕陽，請預約日落前一小時的時段，並搭較晚的巴士（往樂園的末班車為19:50——之後就搭電車）。

## 親子·雨天注意事項

- **嬰兒車：** 可以推到展望台（有電梯）；想放的話4樓有停放區；租借數量有限。
- **排隊：** 持線上指定時段票的話入場等候很短；該避開的是週末的櫃檯隊伍（而且每張還多500日圓）。
- **下雨或起霧：** 展望台在室內，但陰天就沒景色——買當日票前先看官方網站的即時攝影機，不行就退到水族館和商場。
- **懼高：** 玻璃地板很小，可以不走。
