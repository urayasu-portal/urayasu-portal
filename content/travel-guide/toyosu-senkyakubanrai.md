ゆりかもめの市場前駅を出ると、デッキがそのまま提灯の灯る木造の町並みへ続いています。東京の中央卸売市場の隣に建つ江戸テーマの食と温浴の複合施設、**豊洲 千客万来**。東京ディズニーリゾート周辺に泊まる人にとって、都内のたいていの「グルメスポット」にはない2つの利点があります。**舞浜から新木場経由で約30分**であること、そしてマグロを食べすぎたあとに**無料の屋上足湯**と**24時間営業の温泉**が待っていること。チームラボプラネッツから徒歩10分なので、地元ではこの2つをセットで1回の外出として扱います。

## こんな人におすすめ

- 旅行中に一度は、朝5時起きなしで日本の海鮮をきちんと食べたい──寿司、海鮮丼、焼きホタテ、串の玉子焼き。
- [チームラボプラネッツ](/travel-guide/teamlab-planets/)と組み合わせる、徒歩圏の昼食＋回復地点がほしい。
- ホテルの風呂より広くて、いつでも開いていて、電車で行ける温泉がいい。
- 寿司の列に並ぶ間、子どもは串を1本持たせておけば静か、という家族。

{{< note >}}
**名称について。** 食の施設部分は2025年9月1日まで「豊洲場外 江戸前市場」と呼ばれていましたが、以降は施設全体が**豊洲 千客万来**の名称に統一されました。案内板や古い記事には両方の名前が出てきますが同じ場所です。隣の卸売市場**豊洲市場**は別施設で、見学エリアは限られています。
{{< /note >}}

## 何ができる？

### 海鮮の江戸町並み（2〜3階）

本館は木と白壁で江戸の商家の通りを再現した2〜3階建て。寿司のカウンター、海鮮丼、焼き物の屋台、玉子焼き、だし、和菓子、土産物店が並びます。立ち食いカウンター、小さなテーブル、3階のテラスで食べるスタイル。価格は串や甘味の数百円から都内の寿司カウンター相場まで幅があり、海鮮丼は2,000〜4,000円台が市場エリアの標準です。

**営業時間：** 物販店**10:00〜18:00**、飲食店**10:00〜22:00**（一部20:00まで、2階の一部は9:00から）。**年中無休**で市場の休市日も営業。無料Wi-Fi（SSID「SENKYAKU_BANRAI」）あり。クレジットカード・スマホ決済・交通系ICは「店舗により異なる」とされているので、屋台用に現金も持っておきましょう。

### 無料の足湯庭園（8階）

2階の奥から上がった先が**足湯庭園**。長い足湯と、市場のクレーン越しに東京湾を見渡す屋上庭園、ソフトクリーム係のためのベンチ。**無料・入館券不要・9:00〜22:00。** 前日に2万歩歩いた足に贈れる、最高の20分です。小さなタオルを持参（または購入）を。イベント日は短縮営業で、花火大会の日（2026年10月24日）は終日休業です。

### 東京豊洲 万葉倶楽部──24時間温泉（高層棟）

温浴棟は**年中無休・24時間営業**（浴場の清掃3:00〜5:00）。基本のマル得セット──**大人（中学生以上）3,850円＋入湯税150円**──に浴衣・バスタオル・タオルが含まれ、手ぶらで行けます。子どもは割安（小学生2,000円、3歳〜未就学1,400円、3歳未満無料。2026年料金表より。行く前に公式ページで確認を）。館内には箱根・湯河原から運ぶ湯の内風呂と露天風呂、展望足湯（10階・利用者専用）、リクライニングチェアの休憩フロア、食事処、そしてタトゥーや恥ずかしがりの子どもで大浴場が難しいときの**貸切家族風呂（1時間4,500円）**。3時以降は深夜料金が加算され、豊洲で寝たい日のために宿泊室もあります。

タトゥーやタオルの規定は公式サイトに。日本の温浴施設の常として、見えるタトゥーは問題になることがあり、家族風呂がその回避策です。

{{< warn >}}
**豊洲市場のマグロのせりはこの施設の一部ではありません。** せり見学デッキは無料ですが**事前申込の抽選制**（毎月オンラインで申込、集合5:30）。一般の2階見学者通路（5:00〜17:00）は休市日──日曜・祝日・多くの水曜──は閉まります。せりが目的なら別途計画し、早起きを覚悟してください。
{{< /warn >}}

## 東京ディズニーリゾート周辺からの行き方

**舞浜から：**

1. **JR京葉線**で**新木場**──2駅・約6分・IC199円。
2. **東京メトロ有楽町線**で**豊洲**──2駅・約5分・178円。
3. **ゆりかもめ**で1駅、**市場前**──3分・189円。駅の2階デッキが施設に直結（徒歩約4分）。

**片道約30分・566円**、短い乗換2回で、ほぼ地下か屋根付き。新浦安からは京葉線で1駅（3分）足してください。

**ゆりかもめを使わない場合：** 豊洲駅から徒歩約20分。天気がよければ気持ちいい道ですが、市場の昼食後にベビーカーでは長いです。

**浦安駅（東西線）から：** 門前仲町は豊洲に近いものの直通の鉄道はなく、門前仲町からタクシー（約10分）か、東西線→有楽町線（飯田橋経由・遠回り）になります。浦安駅近くのホテルなら、この日はバスで新浦安へ出て京葉線に乗る価値があります。

3路線ともSuica/PASMOで乗れます。ゆりかもめはクレジットカードのタッチ乗車に対応していますが、JR京葉線は非対応──[ICカード・支払いガイド](/travel-guide/ic-card-payment/)参照。

## 半日プラン（チームラボと）

| 時刻 | 内容 |
|---|---|
| 10:00 | チームラボプラネッツ、午前の日時指定チケットで（2〜3時間・裸足。[チームラボの記事](/travel-guide/teamlab-planets/)参照） |
| 13:00 | 徒歩約10分（またはゆりかもめ1駅）で千客万来へ。12時台のピークが緩んだころ遅めの昼食 |
| 14:30 | 2階で軽食と土産──玉子焼き、だし、乾物 |
| 15:00 | 8階の無料足湯で20〜30分 |
| 15:45 | 任意：万葉倶楽部で入浴（2時間）。または帰って[舞浜ユーラシア](/travel-guide/maihama-eurasia-spa/)で |
| 18:00 | 舞浜に戻る |

チームラボなしなら開店（10:00）に合わせて行くと寿司の列が最短で、午後のパーク入園にも余裕で間に合います。

## 子連れ・雨の日の注意

- **ベビーカー**は持ち込み可（置き場はないので通りの中を押して回ることになります）。各階はエレベーターで接続、多機能トイレは1〜3階、**授乳室は温浴棟2階と本館3階**。
- **好き嫌いのある子ども**には、玉子焼き・焼きおにぎり・メロンパン・ソフトクリーム・串がそこら中にあります。3階には海鮮バイキングの店もあり、座って選べる食事ができます。
- **雨：** 通りは屋根付き、温浴棟は屋内。屋外は足湯とテラスだけ（足湯は小雨なら使えます）。チームラボとの組み合わせは雨の日にも向きます。
- **混雑：** 週末の正午前後は満員。平日の開店時間は落ち着いています。
