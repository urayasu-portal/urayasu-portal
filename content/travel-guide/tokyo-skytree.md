東京のランドマークの中で**東京スカイツリー**だけは、こちらから出向くのではなく向こうからディズニーリゾートに来てくれます。**東京ディズニーシー・東京ディズニーランドのバス乗り場から直行バス**が東京スカイツリータウンへ、1,000円・予約不要・約45〜55分──東京駅なし、乗換なし、階段なし。着いた先には634mのタワーと2つの展望台、小さな子どもがしばしば眺めより気に入る**すみだ水族館**、そして300店舗と家族に必要なベビー休憩室を備えた**東京ソラマチ**。川を渡って徒歩20分の[浅草](/travel-guide/asakusa/)と組み合わせるのがいちばん自然な東京のスポットでもあります。

## こんな人におすすめ

- **東京の高い眺めを1回**ほしくて、ベビーカーで地下鉄を乗り換えるよりバスに乗りたい家族。
- **雨や寒い日**：展望台・水族館・モールが全部屋内（天気に左右されるのは眺めだけ）。
- 浅草の日に屋内の後半がほしい。
- [SHIBUYA SKY](/travel-guide/shibuya-sky/)と比べている人：スカイツリーは高く、屋内で、子どもに安く、パークからバスで行ける。SHIBUYA SKYは屋外で写真映えする。

{{< note >}}
**チケット料金は2026年4月に変わりました。** スカイツリーは**日付による変動料金制**に移行し、以前の平日／休日、前売／当日、大人・中人・小人の固定料金表はなくなりました。料金は公式サイトで日付ごとに表示され、年齢区分は**大人15歳以上、子ども6〜14歳、未就学児無料**。「2,100円／3,100円」などの固定料金を載せた古いガイドは現在のものではありません。
{{< /note >}}

## 何ができる？

### 展望台

- **天望デッキ（350m）：** 3層の360度展望、ガラス床、カフェ、ショップ。冬の晴れた日は富士山、普通の日は地平線まで続く街並みが主役。
- **天望回廊（450m）：** さらに100m上るガラス張りの螺旋回廊──「空中散歩」の部分。セット券か、当日デッキの券売機で追加（**大人1,400円／子ども700円**）。

**営業時間（2026年10月）：平日10:00〜22:00、土日9:00〜22:00、最終入場は閉場1時間前。** 狙い目は開場直後（列が短く視界が良い）と日没1時間前（昼・夕日・夜景を1枚のチケットで。ただし最も混むので事前にその時間を予約）。

| | |
|---|---|

休日や繁忙日は高くなるので実際の日付で確認を。未就学児無料なので、大人2人＋小さな子ども2人の家族には比較的安いランドマークです。

### すみだ水族館（ソラマチ5〜6階）

照明の美しい中規模の水族館：上から見下ろすマゼランペンギンのプール、クラゲのゾーン、巨大な「江戸の金魚」の展示、オットセイ。**年中無休──平日10:00〜20:00、土日祝9:00〜21:00、入場は閉館1時間前まで。大人2,700円、高校生2,000円、小中学生1,400円、3歳以上900円。** 薄暗く静かでベビーカー向き、所要約90分。雨の日に幼児連れなら、展望台を飛ばしてここが主役になることも。

### 東京ソラマチ──足元のモール

**全館10:00〜21:00、レストランフロア（6〜7階と30〜31階）は11:00〜23:00。** 大きなフードコートと地下の食品街で昼食は解決。30〜31階のレストランは食事代で眺めがついてきます。家族向け設備：**1階・3階・4階におむつ替え台・授乳室・給湯・電子レンジ付きのベビー休憩室**。タワー側は4階にベビーカー置き場、台数限定のベビーカー貸出、4階のロッカー、展望台内の授乳室。キャラクターショップ（大型のポケモンセンターやジブリ、予約制のカービィカフェなど）もあり、[東京キャラクターストリート](/travel-guide/tokyo-character-street/)の小型版です。

## 東京ディズニーリゾート周辺からの行き方

**直行バス（パークと舞浜のホテルから最も簡単）：** **スカイツリーシャトル**（東武バス・京成バス）が**東京スカイツリータウン（2番乗り場）－錦糸町駅－（一部便は葛西駅）－東京ディズニーシー－東京ディズニーランド**を結びます。**大人1,000円・子ども500円**。パーク発は16便（シー9:40〜21:25、ランド9:50〜21:35）、パーク行きは17便（スカイツリータウン発6:50〜19:50）。**ディズニーシーまで約45分、ランドまで55分**。予約なし・先着順・立席不可なので、夕方の帰りは15分前に並ぶこと。車内で現金・Suica/PASMO・クレジットカードのタッチ決済が使えます。

**浦安駅（東西線）から電車で：** 東西線で**九段下**、半蔵門線で**押上**（タワー直下の駅）──**約45〜50分・IC252円**、乗換1回。速いが高い案：東西線で日本橋、都営浅草線で押上──約36分・359円。

**舞浜から電車で：** 京葉線で八丁堀、日比谷線で人形町、都営浅草線で押上──約45分・540円前後（目安）。正直、バスで。

**押上駅**では東京スカイツリータウンの案内に従って。タワーの入口は4階で、改札からエスカレーター・エレベーターで約7分。

上記すべてSuica/PASMO可。クレジットカードのタッチ乗車は東京メトロ・都営・バスで使えますがJR京葉線では不可。

## バスを往復で使うプラン

| 時刻 | 内容 |
|---|---|
| 9:50 | 東京ディズニーランドのバス乗り場からスカイツリーシャトル（シーは9:40） |
| 10:45 | スカイツリータウン着。午前の静かなうちにすみだ水族館 |
| 12:30 | ソラマチの食のフロアで昼食 |
| 14:00 | 予約した時間で天望デッキ（または徒歩20分で浅草へ行き、夕方戻る） |
| 16:30 | ソラマチで買い物とおやつ |
| 17:30 | パークかホテルへのバス、18:30ごろ着 |

展望台で夕日を見るなら日没1時間前の枠を予約し、遅い便で（パーク行きの最終は19:50発──それ以降は電車で）。

## 子連れ・雨の日の注意

- **ベビーカー：** 展望台まで持ち込み可（エレベーター）。4階に置き場、台数限定の貸出もあり。
- **行列：** オンラインの日時指定券なら入場待ちは短い。避けるべきは週末の窓口の列（しかも1枚500円高い）。
- **雨・霧：** 展望台は屋内ですが、曇りの日は眺めなし。当日券を買う前に公式サイトのライブカメラで確認し、ダメなら水族館とモールへ。
- **高所：** ガラス床は小さく、通らなくても大丈夫。
