## 1. 結論

**この3か月のサイトは「夏祭り1本足打法」だった。** クリック6,495のうち49%が夏イベント記事、27.6%が盆踊り記事1本である。月次では6月543→7月1,808→8月4,081と伸びたが、これは成長ではなく季節ピークだった。

診断の要点は4つ。

1. **posts は健全**。クリックの91%、CTR 4.14%。特に「開店・閉店」クラスタは CTR 5.47% で非季節。ここが本命の資産である
2. **旅行ガイドは伸びている**。8/17を境にクリック54→165（3.1倍）、CTR 1.05%→1.82%。同期間に posts は半減（2,536→1,275）しているので、季節要因では説明できない。**2026-08 の再設計は効いている**
3. **生活ガイドは動いていない**。全期間でクリック23・CTR 0.73%。8/17再設計の前後でも 5→4 クリックで変化なし。**問題はCTRではなく可視性**（表示回数そのものが少ない）
4. **英語ページは表示だけが多い**。表示11,940でクリック73（CTR 0.61%）。ただし内訳を見ると勝てるクエリは限られる（→3章）

Phase 1 で「最優先」と書いた posts→ガイド導線については、GA4 のパス分析が答えを出した。**導線は537記事に存在するが、ほぼ使われていない**（→3章）。

## 7. 分析の限界

正直に書いておく。

1. **16か月データがないため季節性を切り分けられない**。夏イベントがクリックの49%を占めるが、これが例年どおりなのか今年だけなのか判断できない。秋以降の平常値も不明
2. **Core Web Vitals のフィールドデータがない**。Phase 1 の A-2／A-3（画像・レイアウトシフト）の実害を確認できていない
3. **クエリ単位の分析はクリックの41%しかカバーしない**。GSCの匿名化による制約で、これは取得方法では解決できない
4. **再設計の効果判定は2週間の観測**。SEOの反映期間としては短い。10月下旬の再計測が必要
5. **GA4のパス分析はPDFのため数値の精度が粗い**。「約235」などは図から読み取った概算

## 8. 決めてほしいこと

1. **バックログ1〜3を先に着手してよいか**。いずれも工数が小さく確度が高い。改題6件は既存記事のタイトル変更なので、SERPでの見え方が変わる
2. **京葉線の運行情報ガイド（#7）を作るか**。日付付きクエリ（「京葉線 運行状況 2026年8月15日」等）が単発ニュース記事に集まっている。常設の「調べ方ガイド」で受けられるが、当サイトはリアルタイム情報を提供できないため、期待とのずれが残る可能性がある
3. **生活ガイドをどう扱うか**。3か月でクリック23、再設計後も横ばい。順位7〜10位に張り付いており、被リンク2サイトという条件では押し上げが難しい。(a) 現状維持で観察を続ける、(b) 市公式と競合しないニッチ（クリーンセンター営業時間など具体的な事実クエリ）に絞る、(c) 投資を止めて posts と旅行ガイドに集中する
4. **Core Web Vitals をいつ取るか**。9/4の画像最適化から28日後（10月上旬）に取ると、改善効果が測れる
