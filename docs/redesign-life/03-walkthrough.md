## 検証から得た確認事項

1. **urgent 枠は既に機能している**（Q1・Q9が現状○）。二段診断の「段2」はこの拡張であり、壊さないこと
2. ×の3問（Q3・Q6・Q10）はすべて**構造の不在**であり、既存記事の改稿では解決しない → 新設2本と posts連携部品の妥当性を確認
3. △の4問は**「あるのに届かない」**（埋没・改題不足・リンク不足）。旅行ガイドと同じ「分岐不足」パターンであり、診断型改修が処方箋
4. Q10（ニュース→ガイド）は生活ガイド固有の勝ち筋。**postsの92%トラフィックが毎日この導線を通る**ため、単一の改修としては最大のレバレッジ

→ ターゲット構造は10/10。**Step 4（23記事の処遇マッピング）へ進む妥当性を確認**
